# Capture

**Capture** هو استوديو سطح مكتب عربي لتسجيل شروحات الشاشة وإدارتها وتحريرها وتصديرها من مكان واحد. النسخة الحالية مبنية كـ MVP قابل للتشغيل باستخدام Electron وReact وVite، وتعمل محليًا دون رفع التسجيلات إلى خادم.

## ما تم تنفيذه

تتضمن النسخة الحالية واجهة عربية RTL كاملة، وشريط تنقل بين الاستوديو والمحرر والمشاريع والإعدادات. يمكن إنشاء ثلاثة مشاهد افتراضية أو إضافة مشاهد جديدة، والتبديل بينها باستخدام F1 وF2 وF3. لكل مشهد إعدادات مستقلة للشاشة والكاميرا والميكروفون وصوت الجهاز والتكبير الذكي وتتبع المؤشر.

يدعم الاستوديو اختيار شاشة كاملة أو نافذة تطبيق عبر Electron، وتسجيل الشاشة مع صوت النظام، ودمج الميكروفون في مسار صوتي واحد، وإيقاف التسجيل مؤقتًا واستكماله، ثم إنشاء مقطع قابل للمعاينة والتحرير. يعمل اختصار `Ctrl + Shift + R` عالميًا لبدء التسجيل أو إيقافه.

يوفر المحرر المدمج معاينة للمقطع، وخطًا زمنيًا للمقاطع، وتحديد المقطع النشط، وحقول قص البداية والنهاية، وتغيير اسم المقطع، وأدوات واجهة جاهزة للقص والتكبير وحذف الصمت والانتقالات. كما يوفر التصدير إلى WebM عبر نافذة الحفظ المحلية. يظل محرك المعالجة المتقدم للقص الفعلي، وحذف الصمت، والانتقالات، والتكبير الحركي، وتصدير MP4/MOV/GIF مرحلة تالية مناسبة للإصدار الإنتاجي.

يحفظ Capture ملف مشروع بصيغة `.capture.json` يشمل اسم المشروع ونسبته ومعدل الإطارات والجودة والمشاهد وبيانات المقاطع. حفظ الفيديو نفسه يتم محليًا من خلال نافذة التصدير، ولا توجد خدمة رفع أو حسابات أو قاعدة بيانات في هذه النسخة.

## التشغيل من المصدر

```bash
cd capture
pnpm install
pnpm run dev
```

لبناء الواجهة فقط:

```bash
pnpm run build
```

لبناء حزم Linux:

```bash
pnpm run dist
```

بعد النجاح، توجد الملفات داخل `release/`:

| الملف | الاستخدام |
| --- | --- |
| `Capture-0.1.0.AppImage` | تشغيل مباشر على توزيعات Linux الداعمة لـ AppImage |
| `capture_0.1.0_amd64.deb` | تثبيت على Ubuntu وDebian والتوزيعات المتوافقة |

تمت تهيئة أهداف Windows وmacOS داخل إعداد Electron Builder في `package.json`، ويمكن إنتاجها على أنظمة البناء المطابقة لاحقًا.

## بنية المجلد

| المسار | الوظيفة |
| --- | --- |
| `electron/main.cjs` | نافذة Electron، مصادر الشاشة، نوافذ الحفظ والفتح والتصدير، والاختصار العالمي |
| `electron/preload.cjs` | جسر IPC آمن ومحدود بين Electron والواجهة |
| `src/main.jsx` | منطق التطبيق، التسجيل، المشاهد، المشاريع، المحرر، والتصدير |
| `src/styles.css` | نظام التصميم والهوية البصرية العربية RTL |
| `index.html` | نقطة دخول الواجهة |
| `validation/ui-check.md` | سجل اختبارات الواجهة والتغليف |

## ملاحظات الإصدار

هذه نسخة MVP حقيقية قابلة للتشغيل وليست مجرد نموذج بصري. التسجيل المحلي ومعالجة مسار الصوت واختيار مصادر الشاشة والتصدير إلى WebM تعمل داخل بيئة Electron. بعض أدوات المحرر المتقدمة تظهر في الواجهة كجزء من تجربة المنتج لكنها تحتاج إلى محرك فيديو مدمج مثل FFmpeg لتنفيذ المعالجة غير المتلفة والتصدير متعدد الصيغ في إصدار لاحق.
