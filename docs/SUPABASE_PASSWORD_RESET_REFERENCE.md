# مرجع رابط تعيين كلمة المرور

راجعت توثيق Supabase الرسمي في 14 أغسطس 2026 قبل إضافة عملية إعادة تعيين كلمة مرور المدير.

- توثيق `auth.admin.generateLink` يوضح أن المسؤول يستطيع إنشاء روابط البريد، ومنها رابط الاسترداد (`recovery`) ضمن وظائف الإدارة: <https://supabase.com/docs/reference/javascript/auth-admin-generatelink>.
- دليل كلمات المرور الرسمي يوضح أن تدفق إعادة التعيين يرسل للمستخدم رابطًا إلى صفحة عامة، ثم يعيّن المستخدم كلمة مروره الجديدة من صفحة تغيير كلمة المرور؛ كما يشدد على ضرورة ضبط رابط التحويل ضمن قائمة Redirect URLs. <https://supabase.com/docs/guides/auth/passwords>
- رسائل كلمة المرور والدعوات تعتمد على إعداد إرسال البريد الإلكتروني في Supabase؛ خدمة الاختبار الافتراضية محدودة، ويوصي Supabase باستخدام SMTP مخصص للإنتاج. <https://supabase.com/docs/guides/auth/passwords>

قرار التنفيذ: لا تُخزن كلمة المرور ولا تظهر في Notion. يوفر النظام عملية «إرسال رابط تعيين كلمة المرور» على الخادم، ترسل رابطًا آمنًا إلى البريد المسجل للمدير.
